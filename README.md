# 📊 Sales & Profit Analysis Dashboard – Excel

## 📌 Project Overview

This project is an **Excel-based Sales & Profit Analysis Dashboard** created to analyze sales performance, profitability, customer behavior, product categories, order quantities, and yearly business trends.

The project includes **data cleaning, Pivot Tables, data analysis, and an interactive dashboard** to convert raw sales data into meaningful business insights.

## 🎯 Objectives

* Analyze overall sales and profitability
* Track yearly sales performance
* Analyze profit margins
* Compare product categories
* Understand customer types and purchasing behavior
* Analyze order quantities
* Identify important business trends
* Create a clear and interactive Excel dashboard

## 📂 Workbook Structure

The Excel workbook contains the following sheets:

### 1. Cleaned Data

Contains the cleaned and structured dataset used for analysis.

Important fields include:

* Order No
* Order Date
* Customer Name
* City
* State
* Customer Type
* Account Manager
* Order Priority
* Product Name
* Product Category
* Product Container
* Ship Mode
* Ship Date
* Cost Price
* Retail Price
* Profit Margin
* Order Quantity
* Sub Total
* Discount %
* Discount $
* Order Total
* Shipping Cost
* Total

### 2. Pivot Table

Contains Pivot Table analysis for:

* Year-wise Order Total
* Year-wise Profit Margin
* Product Category performance
* Order Quantity
* Average Profit Margin
* Other summarized business metrics

### 3. Dashboard

The dashboard provides a visual representation of the analyzed data using charts and key business metrics.
